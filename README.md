## 一、这是什么

一款面向**考研英语 / 翻译考试**场景的专有名词记忆工具。词库预置 **286 个英语专有名词**，
覆盖人名、地名、作品名、专业名、机构名等六类，每个词条都配有一句**词条介绍**（人物生平、机构职责等），
答错时自动展开，帮你顺带记住背景知识。

设计目标只有三个：

1. **打开就能背** —— 单个 HTML 文件，双击即用，断网也能用。
2. **练得进去** —— 一屏一词，输入即判，答对自动翻页，节奏不被打断。
3. **走得出闭环** —— 错的词自动收集，练完一组可以只针对错题再来一遍。

## 三、核心玩法

### 一屏一词，看词写译文

界面中央是一个英语专有名词（例如 `the Supreme Court`）。在输入框里写下中文译文，
点「确认翻译」或按回车提交。

- **写对了** → 界面压缩、出现一枚「译对了」印章，**自动进入下一词**（约 0.6 秒后翻页，输入法不会被打断）
- **写错了 / 不记得** → 展开完整结果：你写的答案、参考答案、原词，以及**词条介绍**
- **实在想不起来** → 点「不记得」直接看答案，同样算「错」，会进错题清单

### 判断标准（很宽松，别怕写不标准）

系统会比较你写的和参考答案，做了这些容错：

- 忽略大小写、首尾空格、全角/半角标点
- 自动剥离开头的 `the`
- 括号里的补充说明不算数（`华盛顿（州）` ≈ `华盛顿`）
- 支持多答案，用 `/`、`;`、`、` 等分隔（`英国/不列颠` 任一都对）
- 只要有一方包含另一方，且较短的那个不少于 2 个字，也算对

> 举个例：答案是 `亚里士多德`，你写 `亚里斯多德`（错别字）→ 判错；你写 `亚里士多德 `（带空格）→ 判对。

### 顶部信息栏

| 元素 | 含义 |
|---|---|
| 左侧标签 | 当前词属于哪个板块（如「机构名」） |
| ★（右上角） | 加入 / 移出生词本 |
| 🔊（词旁边） | 朗读这个英语单词 |
| 进度条 | 本组词的整体进度 |
| `1 / 2` | 当前是第几个 / 本组共几个 |
| 底部统计 | 本组共几词 · 已答几题 · 正确率 |
| 底部按钮 | 打乱顺序 · 导出 · 导入 · 重置进度 |

## 四、词库结构

共 **286 词**，分为 **6 个板块**，每个板块内部还有更细的类别（`g` 字段）：

| 板块 | 英文 | 词数 | 内部类别 |
|---|---|---|---|
| 人名 | Names | 94 | 哲学家/思想家、科学家、时政/其他人物、文学家/艺术家 |
| 地名 | Place Names | 88 | 国家/地区、大洲/大洋/区域、城市/州/省份 |
| 作品名 | Titles / Works | 13 | 报刊/书籍、法律/法案 |
| 专业名 | Academic Disciplines | 20 | 专业名 |
| 机构名 | Institutions | 38 | 国际组织/机构、名校、地标/其他机构 |
| 其他专有名词 | Others | 33 | 历史时期/运动、身份/属性、宗教、语言 |

### 切换板块

顶部是一排横向可滚动的标签：`全部 286`、`人名 94`、`地名 88`…… 点哪个就只练哪个板块。

### 词条介绍

**286 个词条全部配有介绍**，例如：

> **Aristotle** — 古希腊哲学家，柏拉图的学生、亚历山大的老师，被誉为希腊哲学的集大成者。
> 著作涵盖形而上学、政治学、伦理学、美学等领域，名言"吾爱吾师，吾更爱真理"传世。

介绍**只在答错或没作答时出现**——答对时界面保持极简，不占用你背单词的注意力。

## 五、生词本

遇到不熟的词，点右上角的 ★ 收进来。生词本用来**集中复习你标记过的词**。

进生词本后，顶部标签栏会**变成筛选条**：

```
‹ 全部板块   |   生词本 2   |   人名 1   |   机构名 1
```

- 第一格 `‹ 全部板块` 是返回键，点它回普通板块导航
- 后面几格是**按板块筛选**生词本：数字表示生词本里该板块有几个词
- 生词本里没有词的板块不显示

> **重要**：这是**筛选**，不是归类。它只决定「这次刷哪些词」，不会改动任何词的原有分类。

筛选状态会被记住，下次打开还在。如果筛选的板块被清空了（比如取消收藏），会自动退回「全部」。

## 六、自建词

词库里没有的词，可以通过**导入**加进来。

导入时，凡是「英文 + 中文」齐全、但词库里没有的条目，会自动收进「自建词」，**默认已在生词本**。
自建词和内置词完全平权：能练、能判分、能进生词本、能导出。

取消收藏自建词也是可以的，系统会用「取消记号」记住，重新收藏时自动撤销。

## 七、错题练习

**一组词全部答完（对错都算）后**，卡片下方会出现一条收尾栏：

| 情况 | 显示 |
|---|---|
| 有错题 | `本组做错 3 个` + 按钮「**只练这 3 个错题 ›**」 |
| 全对 | `✓ 这一组全答对了`（不出现按钮） |

点进错题练习后：

- 题组**换成这一组的错题**，顺序与原组一致
- 卡片顶部出现小标：`✎ 错题练习` · `还剩 2 / 2 个没答对` · `退出`
- 判分规则**完全不变**（答错照旧展开词条介绍）
- **答对一个就摘掉一个**，数字实时递减
- 全部清光 → 提示 `✓ 错题都答对了`，给「回到本组词」按钮
- 点「退出」→ 回到进入前的**原题组和原位置**

切换板块、切换筛选、打乱顺序、重置进度、导入数据时，都会**自动退出**错题练习态。
错题练习状态本身不落盘，重开页面不会"假装"还在复习里。

## 八、数据同步（导出 / 导入）

点底部「**导出**」或「**导入**」，从底部弹出面板。两者共用同一个面板，顶部可切换。

### 导出（4 种格式）

| 格式 | 内容 | 用途 |
|---|---|---|
| **备份 (JSON)** | 完整数据（含答题记录、收藏、自建词） | **推荐**，换机迁移 / 留档 |
| **表格 (CSV)** | 生词本全部词条，7 列：英文、中文、板块、类别、学习状态、答题结果、来源 | Excel / WPS / 石墨可直接打开 |
| **纯文本 (TXT)** | 生词本词条，`英文,中文` 逐行（带注释头） | Anki / 墨墨 / 不背单词可导入 |
| **复制到剪贴板** | 同 CSV 内容 | 手机下载不灵时的备用方案 |

导出范围是**整个生词本**（不受当前板块筛选影响）。

导出文件命名带时间戳（如 `生词本-20261002-1230.csv`），多次导出不会互相覆盖。
CSV 带 BOM 头，Excel 打开中文不乱码；含逗号/引号/换行的单元格会标准转义，
以 `=` `+` `-` `@` 开头或纯数字的值会前置制表符，**防止被 Excel 当公式执行**（CSV 注入防护）。

### 导入（3 种格式，自动识别）

把文件拖进来 / 选进来 / 粘贴进来，系统自动嗅探是 JSON、CSV 还是 TXT
（也接受 `英文,中文` 逐行纯文本）。文件通道和粘贴通道都支持。

**导入流程**：

1. **预检** —— 先出统计结论，六行：可识别的词条 / 新增收藏 / 新增自建词 / 已在自建词表 / 已在生词本 / 无法建卡
2. **选合并方式**
   - **合并**（默认，推荐）：保留现有生词本，**只补新的**；不覆盖本机更新的答题进度
   - **替换**：清空后按导入内容重建（本机自建词会被清掉，内置词库词保留）
3. **确认执行** —— 落盘后自动跳到「这次导进来的第一个词」，一眼看到同步结果

**导入与自建词的联动**：

- 词库里没有、但 `英文+中文` 齐全 → 收为**自建词**，默认进生词本
- 匹配策略三级兜底：词条 id → `英文+中文` 组合键 → 唯一的英文/中文
- 导入即视为「要它进生词本」，会撤销之前的「取消收藏」记号

## 九、键盘与手势

### 手机

- **左右滑动** 卡片区域 → 上一词 / 下一词（横向位移超过 62px 触发；有横向/纵向锁定，上下滚动不会误翻页）
- 输入框聚焦时，界面自动进入**紧凑模式**，把键盘空间让出来
- 答对后**保持紧凑**（不收起键盘、焦点自动还给输入框），可以一路答下去不用重新点输入框
- 点词旁的 🔊 朗读（依赖系统语音合成，部分浏览器不支持时会提示）

### 电脑

- **回车** → 第一次提交答案；已在判分态时再按回车 → 下一词
- 输入框内、输入框外都支持回车
- 鼠标按住卡片左右拖动也能翻页

> 输入框右下角的按钮文案会跟着动作变：答题时显示「确认」，判分后显示「下一项」。

## 十一、数据存储

所有数据存在**浏览器 localStorage**，键名统一 `etf_` 前缀：

| 键 | 内容 |
|---|---|
| `etf_favs` | 生词本收藏 |
| `etf_unfavs` | 取消收藏的记号 |
| `etf_custom` | 自建词 |
| `etf_results` | 每个词的判分结果（`ok` / `no`） |
| `etf_phase` | 作答阶段（待答 / 已答） |
| `etf_last` | 上次看到的词（断点续做） |
| `etf_tab` | 当前板块 |
| `etf_favfilter` | 生词本筛选 |
| `etf_dir` | 练习方向（英→中 / 中→英） |
| `etf_shuffle` | 是否打乱顺序 |

> ⚠️ **数据在浏览器本地**。清理浏览器数据 / 换设备会丢失。重要进度请用「导出 → 备份 (JSON)」。

## 十二、常见问题

**Q：进度会丢吗？**
A：正常情况下不会。进度实时写入本地，每次操作都保存。但如果清理浏览器缓存、或用无痕模式，就会丢。想长期保存请导出 JSON 备份。

**Q：换手机怎么同步？**
A：在旧设备「导出 → 备份 (JSON) → 复制到剪贴板」，在新设备「导入 → 粘贴 → 合并」。推荐用「合并」，不会覆盖新设备上更新的进度。

**Q：为什么答对了界面就压缩了？**
A：这是**故意设计**的——答对时只给你一枚「译对了」印章，不展开答案明细，一是让你一路答下去不被打断，二是不让正确答案占你的注意力。答错时才会展开全部信息。

**Q：词库里没有我要的词怎么办？**
A：导出模板 → 按 `英文,中文` 格式补几行 → 再导入进来，它就会变成「自建词」并自动进生词本。

**Q：能练「中→英」吗？**
A：可以，右上角有方向切换。反过来就是看中文写英文。

**Q：为什么有的词条没有介绍？**
A：286 个词条都有介绍。如果没看到，说明这道题你**答对了**——介绍只在答错时出现。

**Q：手机上点导出没反应？**
A：部分手机浏览器限制下载。改用「复制到剪贴板」，再粘到备忘录/微信里保存。
